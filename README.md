# 🍏 SupportDesk AI — Інтелектуальна обробка звернень клієнтів

Внутрішній веб-додаток для служби підтримки клієнтів з автоматизованим AI-аналізом вхідних запитів, визначенням пріоритетів, категоризацією та генерацією чернеток відповідей. Інтерфейс розроблено в чистому, мінімалістичному **Apple-style** дизайні у світлих тонах.

## 📋 Реалізований функціонал (згідно з ТЗ)

1. **Додавання звернення**:
   - Охайна модальна форма з полями: **Ім'я клієнта** + **Текст звернення**.
   - Дані зберігаються в базі даних та персистентному сховищі.
2. **Список звернень**:
   - Відображення карток усіх збережених запитів.
   - Дані надійно зберігаються та **лишаються після перезавантаження сторінки**.
   - Живий пошук за клієнтом / змістом.
   - Кастомний інтерактивний дропдаун фільтрації за пріоритетом та таби статусу (Усі / Очікують / Опрацьовані).
   - Можливість безповоротного видалення звернень.
3. **Кнопка «Аналізувати (AI)»**:
   - Звернення надсилається до ШІ (Google Gemini API / OpenAI).
   - **Структурована відповідь (окремі поля в базі даних та UI)**:
     - 🔴 🟡 🟢 **Пріоритет**: `низький` / `середній` / `високий` (з кольоровими індикаторними пілюлями).
     - 🏷️ **Категорія**: `оплата`, `доставка`, `скарга`, `технічне`, `інше`.
     - 📝 **Короткий підсумок**: чітко 1 лаконічне речення.
     - 💬 **Чернетка відповіді клієнту**: ввічлива, структурована відповідь із кнопкою швидкого копіювання в буфер обміну.
   - Результат аналізу зберігається на картці звернення з можливістю повторного оновлення аналізу.
4. **Дизайн та естетика**:
   - Мінімалістичний інтерфейс у стилі Apple: світла кольорова гама (`#FBFBFD`), делікатні рамки, матове скло (`backdrop-blur`), м'які тіні та плавні мікроанімації.

## 🛠️ Стек технологій

| Складова | Технологія |
| :--- | :--- |
| **Фреймворк** | [Next.js 15+ (App Router)](https://nextjs.org/) |
| **Мова** | TypeScript |
| **Стилізація** | Tailwind CSS v4 (Apple Minimalist System) |
| **База даних & ORM** | Prisma ORM (SQLite / PostgreSQL) + відмовостійкий serverless адаптер |
| **Штучний інтелект** | Google Gemini API (`gemini-2.5-flash` / `gemini-3.5-flash-lite`), OpenAI SDK |
| **Іконки** | Lucide React |
| **Деплой** | Vercel Serverless |

│   │   ├── Header.tsx              # Навігаційна шапка з логотипом SD

│   │   ├── TicketCard.tsx          # Картка звернення з блоком AI-аналізу

│       ├── llm.ts             # Інтеграція з Gemini/OpenAI + нормалізація JSON
│       ├── prisma.ts          # Клієнт Prisma
│       └── types.ts           # TypeScript інтерфейси
├── .env.example               # Приклад змінних середовища

## 🚀 Локальний запуск

### 1. Клонування репозиторію:
```bash
git clone https://github.com/ziggerman/TZ-Junior-Developer.git
cd TZ-Junior-Developer
```

### 2. Встановлення залежностей:
```bash
npm install
```

### 3. Налаштування змінних оточення (`.env`):
Створіть файл `.env` у корені проєкту:
```env
DATABASE_URL="file:./dev.db"

# Вкажіть ваш API-ключ Gemini або OpenAI:
GEMINI_API_KEY="AIzaSy..."
# OPENAI_API_KEY="sk-..."
```

### 4. Ініціалізація бази даних:
```bash
npx prisma db push
```

### 5. Запуск сервера розробки:
```bash
npm run dev
```
