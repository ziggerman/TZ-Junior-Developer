# 🍏 AI-обробка звернень для служби підтримки (SupportDesk AI)

Сучасний, мінімалістичний внутрішній веб-застосунок у стилі **Apple** для служби підтримки клієнтів з інтелектуальним AI-аналізом вхідних звернень, визначенням пріоритетів, категорій та миттєвою генерацією персоналізованих відповідей.

---

## ✨ Реалізований функціонал

1. **Додавання звернення**:
   - Форма: ім'я клієнта + текст звернення.
   - Швидкі готові шаблони для тестування в 1 клік.
   - Дані надійно зберігаються в базі даних.
2. **Список звернень**:
   - Відображення всіх збережених запитів.
   - Зберігаються після перезавантаження сторінки або зміни сесії.
   - Швидкий пошук та фільтри (Усі / Очікують / Опрацьовані / За пріоритетом).
   - Лічильники статистики в режимі реального часу.
3. **Кнопка «Аналізувати (AI)»**:
   - Звернення надсилається до LLM (OpenAI / Claude / Gemini / Groq).
   - **Структурована відповідь** (окремі поля в базі даних та UI):
     - 🔴 🟡 🟢 **Пріоритет**: *низький* / *середній* / *високий*
     - 🏷️ **Категорія**: *оплата* / *доставка* / *скарга* / *технічне* / *інше*
     - 📝 **Короткий підсумок**: 1 лаконічне речення
     - 💬 **Чернетка відповіді клієнту**: ввічливий персоналізований текст із можливістю копіювання в буфер обміну в 1 клік.
4. **Мінімалістичний дизайн у стилі Apple**:
   - Світлі тони (`#FBFBFD`, `#FFFFFF`), розмиття фону (frosted glass), витончена типографіка SF Pro / Inter.
   - М'які тіні, плавні переходи та мікроанімації.
5. **Гнучкість налаштування LLM**:
   - Ключ можна передати через змінні оточення `.env` або ввести безпосередньо у модальному вікні налаштувань у правому верхньому кутку.

---

## 🛠️ Стек технологій

- **Фреймворк**: [Next.js 15+ (App Router)](https://nextjs.org/)
- **Мова**: TypeScript
- **Стилізація**: Tailwind CSS (Apple Minimalist System)
- **База даних**: Prisma ORM (SQLite за замовчуванням / PostgreSQL для Neon або Supabase)
- **ШІ (LLM)**: OpenAI API (`gpt-4o-mini`), Anthropic Claude (`claude-3-5-haiku`), Google Gemini (`gemini-1.5-flash`), Groq
- **Іконки**: Lucide React

## 🚀 Швидкий запуск локально

### 1. Клонування та встановлення залежностей:
```bash
git clone <URL_РЕПОЗИТОРІЮ>
cd "TZ Junior Developer"
npm install
```

### 2. Налаштування змінних оточення (`.env`):
Створіть файл `.env` (або скопіюйте з `.env.example`):
```env
DATABASE_URL="file:./dev.db"

# Вкажіть хоча б один ключ LLM (або введіть його в UI після запуску):
OPENAI_API_KEY="sk-..."
# ANTHROPIC_API_KEY="sk-ant-..."
# GEMINI_API_KEY="AIzaSy..."
# GROQ_API_KEY="gsk_..."
```

### 3. Ініціалізація бази даних:
```bash
npx prisma db push
```

### 4. Запуск сервера розробки:
```bash
npm run dev
```
Відкрийте [http://localhost:3000](http://localhost:3000) у вашому браузері.

## ☁️ Деплой на Vercel

1. Завантажте репозиторій на GitHub.
2. Перейдіть на [Vercel](https://vercel.com) та імпортуйте репозиторій.
3. Додайте змінні оточення в налаштуваннях проєкту Vercel (`Settings -> Environment Variables`):
   - `OPENAI_API_KEY` (або `ANTHROPIC_API_KEY` / `GEMINI_API_KEY`)
   - `DATABASE_URL` (Використовуйте безкоштовний PostgreSQL від [Neon.tech](https://neon.tech) або [Supabase](https://supabase.com)).
4. Натисніть **Deploy**.

> **Порада для тестування на Vercel**: У застосунку реалізовано модальне вікно **«Налаштування AI»**, що дозволяє будь-якому користувачеві протестувати застосунок зі своїм власним API-ключем прямо в браузері.

## 📹 Підготовка до відео (2–3 хв)

План розповіді для демонстраційного відео:
1. **Демонстрація функціоналу (1-1.5 хв)**:
   - Показати створення звернення (вручну або через швидкі шаблони чи кнопку "Демо-звернення").
   - Натиснути кнопку **«Аналізувати (AI)»**.
   - Показати результат: окремі поля (пріоритет зі статусною пілюлею, категорія, 1 речення підсумку та чернетка відповіді).
   - Скопіювати чернетку відповіді в буфер обміну.
   - Продемонструвати роботу фільтрів та пошуку.
2. **Проблема / баг та його вирішення (40 сек)**:
   - *Приклад*: Різні LLM повертали відповіді з markdown-обгортками ` ```json ... ``` ` або різними варіантами пріоритетів (наприклад англійською "high" замість української "високий").
   - *Вирішення*: Реалізовано стійкий парсер та нормалізатор у `src/lib/llm.ts`, який автоматично очищає синтаксичні обгортки та нормалізує поля до єдиного типу.
3. **Як використовувався AI (30 сек)**:
   - Для розробки архітектури, створення мінімалістичного Apple-інтерфейсу, генерації схем Prisma та налаштування багатопровайдерного клієнта ШІ.
